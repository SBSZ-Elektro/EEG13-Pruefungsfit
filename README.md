# Prüfungsfit EEG 13

Lernseite zur Vorbereitung auf die Gesellenprüfung Elektroniker/-in für Energie- und Gebäudetechnik (EEG 13), gestaltet im Layout des Staatlichen Beruflichen Schulzentrums Bamberg, Abteilung Elektrotechnik.

Bereiche: Lernlandkarte mit Karteikarten (3 Fächer) und Quiz je Thema, Rechentrainer mit Zufallswerten, Prüfungsmix, 8-Wochen-Plan.

- Eine einzige Datei: `index.html` (Logo eingebettet, keine externen Abhängigkeiten)
- Der Lernfortschritt wird nur lokal im Browser gespeichert (`localStorage`), es werden keine personenbezogenen Daten erfasst.
- Veröffentlichung über GitHub Pages: *Settings → Pages → Deploy from a branch → main / (root)*

Inhaltliche Grundlage: „Prüfungsfit EIE 13“ der Staatlichen Berufsschule 1 Bayreuth (https://bs1-et.github.io/EIE13-Pruefungsfit/). Die Wiederholungsblätter (PDF) werden von dort verlinkt.
